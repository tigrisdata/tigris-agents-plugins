## About Tigris

Tigris is a globally distributed, S3-compatible object storage service. Store files, serve assets, and manage data with automatic geo-routing, copy-on-write forks, and zero-downtime migrations.

- Website: https://www.tigrisdata.com
- Docs: https://www.tigrisdata.com/docs
- Dashboard: https://console.tigris.dev
